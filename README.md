# Mosquitto broker (RKf)

Сборка официального приложения Mosquitto broker для Home Assistant. Она сделана для приборов Electrolux, Ballu и Polaris, которые настраиваются через приложение Hommyn.

Такие приборы подключаются к своему брокеру MQTT, но подписку на темы отправляют с идентификатором пакета 0. Официальный Mosquitto с версии 2.0.16 эту подписку отвергает и отключает устройство, поэтому в Home Assistant оно не появляется. В этой сборке проверка снята, и прибор остаётся на связи. Как это выглядит в журнале брокера, разобрано в обсуждении [Hommyn/local_mqtt#1](https://github.com/Hommyn/local_mqtt/issues/1).

В остальном приложение совпадает с официальным [Mosquitto broker](https://github.com/home-assistant/addons/tree/master/mosquitto): те же порты, вход пользователями Home Assistant, локальные логины и TLS. Номер версии тоже совпадает с официальным.

## Установка

1. В Home Assistant откройте **Настройки → Приложения → Магазин приложений**.
2. В меню магазина выберите **Репозитории** и добавьте `https://github.com/Anat0l/hass-mqtt-rkf`.
3. Установите **Mosquitto broker (RKf)**.

Официальное приложение Mosquitto broker занимает те же порты. Одновременно с этой сборкой оно не запустится.

## Порты

| Порт | Назначение |
|---|---|
| 1883 | MQTT |
| 1884 | MQTT через WebSocket |
| 8883 | MQTT с TLS |
| 8884 | MQTT через WebSocket с TLS |
